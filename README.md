# santa-bot — Тайный Санта в Telegram

Бот для обмена подарками. Участники присоединяются по ссылке, пишут пожелания, организатор проводит жеребьёвку — каждый получает в личку имя своего получателя и его пожелание. Получатель не знает, кто ему дарит. Санта и получатель могут анонимно переписываться.

## Возможности

- **Жеребьёвка** без подарков самому себе и без взаимных пар (A→B и B→A одновременно). Минимум 3 участника, все допустимые распределения равновероятны.
- **Пожелания**: написать, дополнить, заменить. Статус «✅ готово / ⏳ ещё дописываю» участник меняет сам. После жеребьёвки любое изменение пожелания сразу уходит Санте.
- **Статус «🛍 подарок куплен»** — участник отмечает сам, в «Участниках» виден общий прогресс.
- **Анонимная переписка** Санта ↔ получатель: текст, фото, видео, гифки, стикеры. Голосовые, кружки и контакты не пересылаются — они выдают отправителя. Сообщения копируются без пометки «переслано от».
- **Настройки игры** (организатор): бюджет, дедлайн пожеланий, дата вручения. Об изменениях бот уведомляет всех участников.
- **Напоминания** (раз в день, с `REMINDER_HOUR`, по умолчанию 11:00 МСК):
  - до дедлайна пожеланий — каждый день, включая сам день дедлайна, тем, у кого пожелание не готово;
  - после дедлайна — организатору: сколько пожеланий готово, можно проводить жеребьёвку;
  - до вручения — каждый день (кроме дня вручения), тем, кто ещё не отметил «подарок куплен».
  Частота — константы `WISH_EVERY_DAYS` и `GIFT_EVERY_DAYS` в `src/reminders.js` (сейчас 1 = каждый день).
- **Раскрытие Сант**: организатор с подтверждением рассылает всем, кто кому дарил.
- **Фразы уведомлений**: каждое уведомление = случайная фраза + служебный блок бота (получатель, сроки, пожелание), поэтому фраза не может потерять важное. Пулы фраз:
  - приветствие, жеребьёвка, раскрытие;
  - напоминания разбиты на 7 ступеней по номеру напоминания конкретному участнику (1-е, 2-е … 7-е и дальше): чем дольше человек тянет, тем настойчивее тон. В день дедлайна пожеланий — отдельный пул «последний день». Границы — `STAGE_STARTS` в `src/texts.js`, подписи в боте пересчитываются сами;
  - обращения и междометия — случайно в начале любого уведомления («Ну чё, чел! …»), фразочки — случайно в конце.

  Стандартные фразы — в `src/texts.js`. Свои фразы для игры добавляет любой участник: «ℹ️ Об игре» → «💬 Фразы уведомлений». Удаляет фразы только организатор; авторы не показываются. Подстановки: `{name}`, `{title}`, `{days}`, `{date}`, `{receiver}`, `{santa}`, `{count}` — бот проверяет, что они подходят к уведомлению. До 100 своих фраз на уведомление (до 200 в обращениях, междометиях и фразочках), до 300 символов; длинные списки листаются по 10.

  Пак фраз можно загрузить в игру скриптом: `node scripts/import-phrases.js <pack.json> <КОД_ИГРЫ> [--dry-run]`. Паки с приватным содержимым держите вне репозитория.
- **Кнопки**: всё управление — через меню внизу экрана и кнопки под сообщениями; команды тоже работают.

## Организатор — такой же участник

Организатор видит в интерфейсе ровно то же, что и остальные: свою пару, свою переписку, общий список участников со статусами. Дополнительно — только кнопки управления игрой и после жеребьёвки список тех, кому не удалось доставить сообщение (без пар).

## Запуск на Cloudflare Workers (бесплатно, без карты)

Бот работает на серверах Cloudflare: Telegram присылает обновления на webhook, данные хранятся в D1 (SQLite), напоминания — по Cron раз в час. Компьютер нужен только для деплоя; доступ к `api.telegram.org` с него не требуется.

Все команды — из папки проекта.

1. Зависимости:

```bash
npm install
```

2. Вход в Cloudflare (откроется браузер → «Allow»):

```bash
npx wrangler login
```

3. База данных — команда выведет `database_id`, его нужно вписать в `wrangler.toml` вместо `REPLACE_WITH_DATABASE_ID`:

```bash
npx wrangler d1 create santa-bot
```

4. Таблицы:

```bash
npm run db:migrate
```

5. Секреты — токен от @BotFather и секрет webhook (латиница, цифры, `_`, `-`; сгенерировать: `[guid]::NewGuid().ToString('N')` в PowerShell):

```bash
npx wrangler secret put BOT_TOKEN
```

```bash
npx wrangler secret put WEBHOOK_SECRET
```

6. Деплой — выведет адрес `https://santa-bot.<поддомен>.workers.dev`:

```bash
npm run deploy
```

7. Регистрация webhook — открыть в браузере `https://santa-bot.<поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>`, ответ `{"ok":true,...}`.
   Если `workers.dev` не открывается: вписать адрес в `PUBLIC_URL` в `wrangler.toml`, снова `npm run deploy` — cron зарегистрирует webhook в течение часа.

8. Проверка — написать боту `/start`. Логи в реальном времени: `npm run logs`.

Обновление после правок кода — `npm run deploy`. Новые миграции — `npm run db:migrate`.

### Лимиты бесплатного тарифа

| Ресурс | Лимит | Для бота |
|---|---|---|
| Запросы | 100 000 / день | одна игра — сотни в день |
| CPU | 10 мс на запрос | ожидание Telegram и D1 не считается |
| Подзапросы (Telegram API + D1) | 50 на вызов | поэтому в игре максимум 40 участников |
| D1 | 5 млн чтений, 100 тыс. записей / день, 5 ГБ | с огромным запасом |
| Cron | 5 триггеров на аккаунт | используется 1 |

Настройки в `wrangler.toml` → `[vars]`: `BOT_USERNAME`, `BOT_TIMEZONE` (по умолчанию `Europe/Moscow`), `REMINDER_HOUR` (по умолчанию 11), `PUBLIC_URL`.

## Как играть

| Кто | Действие |
|---|---|
| Организатор | «🎄 Создать игру» → название → настроить бюджет и даты → разослать ссылку-приглашение |
| Участники | открывают ссылку → «Start» → присылают пожелание сообщением |
| Все | «👥 Участники» — кто в игре и статусы; «ℹ️ Об игре» — бюджет и даты |
| Организатор | «ℹ️ Об игре» → «🎲 Провести жеребьёвку», когда пожелания готовы у всех |
| Участники | «🎁 Кому я дарю» — получатель, его пожелание, «✉️ Написать получателю», «🛍 Подарок куплен»; «✉️ Написать Санте» |
| Организатор | «ℹ️ Об игре» → «🎉 Раскрыть Сант» после вручения |

Бот работает только в личных сообщениях — в группах пожелания и пары были бы видны всем.

## Ограничения

- Одновременно можно участвовать в одной открытой игре. После жеребьёвки можно вступить в новую — она станет текущей.
- В игре от 3 до 40 участников.
- Пары и пожелания хранятся в D1 открытым текстом: их видит владелец аккаунта Cloudflare.
- Webhook обрабатывает обновления по одному (`max_connections: 1`): обработчики читают и пишут игру целиком.

## Структура

```
src/
  worker.js         — точка входа Worker: /webhook, /setup, cron
  bot.js            — сборка бота: хелперы, маршрутизация кнопок и сообщений
  handlers/game.js  — игра: создание, вступление, настройки, жеребьёвка, раскрытие
  handlers/wish.js  — пожелания, «Кому я дарю», статусы
  handlers/chat.js  — анонимная переписка
  reminders.js      — расписание и тексты напоминаний
  draw.js           — алгоритм жеребьёвки
  dates.js          — разбор дат, часовой пояс
  ui.js             — кнопки, меню, общие тексты
  texts.js          — пулы фраз уведомлений и градации напоминаний
  handlers/phrases.js — управление фразами в боте
  storage.js        — хранилище D1 (unit of work)
migrations/         — схема D1
test/               — тесты: npm test (D1 эмулируется через node:sqlite)
wrangler.toml       — конфиг Cloudflare
```
